## Инструкция по запуску тестов

### В фреймворке использовались следующие технологии:

Язык программирования: **Java**
Фреймворки и библиотеки:
UI тестирование: **Selenium**, **WebDriver**, **TestNG**
API тестирование: **RestAssured**,  **TestNG**
Отчетность: **Allure Reports**
Сборщики проектов: **Maven**
Паттерны проектирования: **Page Object Model (POM)**, **Builder**, **Factory**

### Инструкция запуска

В файле config.properties нужно указать:
1. Логин
2. Пароль
3. Базовый адрес
4. Токен (Можно получить по пути **Profile → API Keys → Generate API Key**)

Для запуска нужно ввести в терминал комманду: **mvn clean test**

!!!При создании Виджета не был обнаружен тип "Task Progress"

Также, выбор фильтра по умолчанию установлен на выбор первого с "filter' в названии, что предпологает наличие такого в списке.
Создание фильтра реализовано не было. 
Dashboard и Widget создаются со всеми значениями, кроме названия, по умолчанию, но при необходимости, можно настроить более детально через builder.

API:

- Создание Dashboard с недостаточными параметрами (Негативный тест)

UI:
- Создание нового Widget
